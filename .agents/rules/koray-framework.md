# Koray Framework & Visual Semantics Directives

## 1. Brand & Domain Metadata
- Target Domain: `seo-byhighsoftware99.com`
- Primary Brand Entity: `HighSoftware99`
- Target Primary Keyword: `SEO by HighSoftware99`

## 2. Linguistic Rules (Algorithmic Authorship)
- NO hedging language (e.g., NEVER use: "maybe", "can help", "we believe", "should", "could").
- MUST use factual, declarative, active-voice statements (e.g., "HighSoftware99 automates technical page speed optimization.").
- Maximize Entity-Attribute-Value (EAV) density in every paragraph.

## 3. Visual Semantics & Layout Rules
- **Centerpiece Annotation:** The top 400px of every page MUST contain an interactive or structured utility centerpiece (e.g., speed test input, audit bar, comparison table, or calculator).
- **DOM Efficiency:** Keep DOM node count under 1200 nodes per page to minimize Google's Cost of Retrieval (CoR).
- Standard HTML5 semantic wrappers only: `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<aside>`, `<footer>`.

## 4. Linking Rules
- Links must ALWAYS be placed inside contextual annotation blocks (2-3 sentences justifying the relationship).
- NEVER use generic anchor text ("click here", "learn more"). Anchor text MUST be explicit entity names.
